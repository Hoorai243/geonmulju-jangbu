# 건물주 장부

월세·관리비·보증금 입금 여부를 한눈에 관리하는 건물주용 PWA(홈 화면 설치형 웹앱).
디지털에 익숙하지 않은 중년~노년층도 쓸 수 있도록 **큰 글씨, 큰 버튼, 명확한 색, 한 화면 한 작업**을 우선했습니다.

## 어떻게 켜서 보나요 (내 컴퓨터에서 확인)
1. [Node.js](https://nodejs.org)가 설치돼 있어야 해요.
2. 이 폴더에서 아래를 실행:
   ```
   npm start
   ```
3. 브라우저에서 `http://localhost:5178` 접속.

> 앱 아이콘을 다시 만들려면 `npm run icons`.

## 인터넷에 올려서 폰에 설치하려면 (배포)
- 이 폴더 전체를 **정적 호스팅**(예: GitHub Pages, Netlify, Vercel)에 그대로 올리면 됩니다.
  빌드 과정이 없어요. HTTPS 주소로 접속하면 폰 브라우저에서 "홈 화면에 추가"로 설치됩니다.
- 서비스워커(오프라인)와 지문·생체 로그인은 **HTTPS(또는 localhost)**에서만 동작합니다.

## 어디에 저장되나요
- 지금은 **이 기기 안(브라우저 저장소, IndexedDB)**에만 저장돼요.
- 저장 위치를 담당하는 코드(`js/db.js`)만 바꾸면 나중에 인터넷 서버로 옮길 수 있게 설계했습니다.
- 은행 자동 연동(오픈뱅킹)을 대비해 입금 기록은 별도 표(`payment_log`)로 분리해 뒀습니다.

## 폴더 구조 (요약)
```
index.html            앱 뼈대
manifest.webmanifest  홈 화면 설치 정보
sw.js                 오프라인 저장(서비스워커)
css/styles.css        디자인 시스템(색·크기·간격)
icons/                앱 아이콘 + 생성 스크립트
js/
  app.js              시작점 + 화면 주소 연결
  router.js           화면 전환
  db.js               저장소(교체 가능)
  store.js            업무 규칙(요금·납부상태·보증금 계산)
  matching.js         입금자명 느슨한 매칭
  auth/               로그인(비밀번호·지문) + 본인인증 자리(스텁)
  notify/             알림(발송 통로 분리)
  export/             엑셀·이미지 내보내기
  ui/, screens/       화면들
PRODUCT.md, DESIGN.md 제품·디자인 기준 문서
CLAUDE.md             프로젝트 규칙
```

## 개인정보 원칙
- 세입자의 **계좌번호·주민등록번호는 절대 받지 않습니다.**
- 비밀번호는 알아볼 수 없는 형태로 해싱해 이 기기 안에만 저장합니다.
